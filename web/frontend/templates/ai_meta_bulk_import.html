Import Form

Hanya layer nasional, bridging, fraud, dan temporary yang diizinkan untuk bulk import

Format JSON array dengan fields: diagnosis, field, isi, sumber (required), rs_id, region_id (optional)

JSON Format Guide

Required Fields:

  • diagnosis - ICD code (e.g., "A00.0")
  • field - Field name (e.g., "keluhan", "diagnosis_awal")
  • isi - Rule content/description
  • sumber - Source reference

Optional Fields:

  • rs_id - Hospital ID (integer or null)
  • region_id - Region ID (integer or null)

Example:

[
  {
    "diagnosis": "A00.0",
    "field": "keluhan",
    "isi": "Pasien dengan kolera harus menunjukkan gejala diare berair yang hebat",
    "sumber": "Permenkes No. 5 Tahun 2024",
    "rs_id": null,
    "region_id": null
  },
  {
    "diagnosis": "A00.1", 
    "field": "diagnosis_awal",
    "isi": "Diagnosis kolera harus dikonfirmasi dengan pemeriksaan laboratorium",
    "sumber": "Permenkes No. 5 Tahun 2024",
    "rs_id": null,
    "region_id": null
  }
]

⚠️ Import Guidelines

  • • Hanya layer nasional, bridging, fraud, dan temporary yang diizinkan
  • • Rules yang diimport akan langsung mendapat status "official"
  • • Pastikan JSON format valid sebelum submit
  • • Semua field required harus diisi
  • • Import tidak bisa di-undo, pastikan data sudah benar
